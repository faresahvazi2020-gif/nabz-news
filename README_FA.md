# نبض | وب‌سایت خبری هوشمند

نسخهٔ اولیهٔ آمادهٔ انتشار روی GitHub Pages با هاست رایگان.

## امکانات فعلی
- طراحی واکنش‌گرا و فارسی/راست‌چین با ظاهر تیره
- دسته‌بندی خبرها: هوش مصنوعی و فناوری، امنیتی و نظامی، سیاست، فوتبال، بازارها و اقتصاد، رمزارز
- دریافت خبر از Google News RSS و نمایش لینک منبع اصلی
- به‌روزرسانی خودکار داده‌ها به‌صورت ساعتی با GitHub Actions
- ساخت خلاصهٔ روزانهٔ ۲۴ ساعت گذشته در اجرای ۰۷:۰۰ به وقت تهران
- نوار بازار با ویجت TradingView (ممکن است داده‌ها با تأخیر باشند)

## انتشار رایگان
1. در GitHub یک حساب بساز یا وارد حساب خودت شو.
2. یک مخزن عمومی جدید با نام `nabz-news` بساز.
3. تمام فایل‌های این پوشه را در شاخهٔ `main` مخزن بارگذاری کن.
4. از مسیر **Settings → Pages → Build and deployment**، گزینهٔ **GitHub Actions** را انتخاب کن.
5. از مسیر **Actions** اجرای workflow با نام **Update news and publish site** را باز کن و در صورت نیاز **Run workflow** را بزن.
6. بعد از موفقیت، آدرس سایت در **Settings → Pages** نمایش داده می‌شود؛ معمولاً به شکل `https://USERNAME.github.io/nabz-news/`.

## زمان‌بندی
- به‌روزرسانی ساعتی: دقیقهٔ ۷ هر ساعت به وقت UTC.
- گزارش روزانه: ۰۷:۰۰ به وقت تهران (۰۳:۳۰ UTC).
- زمان‌بندی GitHub Actions ممکن است در ساعات پرترافیک با تأخیر اجرا شود؛ «رأس ساعت» تضمین‌شده نیست.

## نکات مهم و محدودیت‌ها
- در این نسخه، «خلاصه» به‌صورت گزینش و فهرست‌کردن تیترهای تازهٔ ۲۴ ساعت گذشته ساخته می‌شود؛ خلاصه‌سازی معنایی با مدل هوش مصنوعی هنوز فعال نیست و برای آن باید سرویس مدل و کلید API امن در GitHub Secrets اضافه شود.
- Google News RSS گردآورندهٔ تیتر و لینک است؛ برای صحت، جزئیات و متن کامل به ناشر اصلی مراجعه کن.
- دسترسی و پایداری RSS به سرویس و محدودیت‌های آن وابسته است.
- نوار بازار از ویجت TradingView استفاده می‌کند. نماد USD/IRR ممکن است در منطقه یا منبع در دسترس نباشد؛ می‌توان آن را با نماد معتبر موردنظرت جایگزین کرد.
- این پروژه توصیهٔ سرمایه‌گذاری یا تأیید صحت مستقل خبرها ارائه نمی‌کند.

## اجرای محلی
نیاز به Python 3.10+:
```bash
python scripts/update_news.py
python -m http.server 8000
```
سپس `http://localhost:8000` را باز کن.
